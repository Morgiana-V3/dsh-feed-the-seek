# 使用与开发参考

## 已有能力

| 能力 | 当前行为 |
| --- | --- |
| 认知 | 记录用户资料、习惯、项目约定，以及用户提供的游戏规则、设定等具体知识，保留领域、版本与条件 |
| 经历 | 记录发生过的事、执行结果与纠正，不作为待办管理器 |
| 共鸣 | 记录交流边界、双方形成的相处方式，不按对话次数自动增加亲密度 |
| 自我 | 保留行为观察与反馈；根据证据整理、融合和修正，累积后形成稳定倾向与人格描述 |
| 更新与淡忘 | 后台提出 ADD / UPDATE / DELETE / NONE；DELETE 表示失效并保留历史；重要记忆与普通记忆采用不同淡忘规则 |
| 情绪 | 近期事件影响表达；状态随时间衰减，事情解决后可恢复；拟人状态不应降低工作质量 |
| 本地检索 | 本地 SQLite 保存记忆，按关键词、关联线索和个人资料召回，无需额外向量服务 |
| 语义增强 | 支持 OpenAI 兼容 Embeddings、Ollama `/api/embed`、火山方舟多模态文本输入；向量仍保存在本机 |
| 可查阅 | 可查看记录、来源、变化、整理任务与召回结果；没有逐条手工修改/删除记忆入口，可创建新的伙伴实例 |

这些是模型辅助功能，提炼、融合与表达仍会受会话模型影响；不能保证每句话都被记录，也不能保证每次更新都准确。

## 何时影响对话

1. **回合开始**：把称呼、通用偏好、相处方式与稳定人格放入系统提示的稳定部分。
2. **处理用户消息**：召回相关往事和近期状态，作为本回合上下文；工作中的模型调用可以据此调整表达和执行方式。
3. **长任务中**：默认每 5 个步骤检查一次；只有新的用户证据才会触发中途整理。回合结束再整理尚未处理的事件。
4. **后台整理完成**：更新本地记忆。本回合自动注入快照保持稳定，后续用户消息或上下文压缩后刷新；新会话能读取同一伙伴的适用记忆。
5. **模型主动回忆**：可调用 `yuwen_recall` 查找更具体的内容；它不是手动写入工具。

所以它会影响模型生成与工作过程，并非只在最终回复上修改语气。四元操作由后台整理器提出并校验执行，主 Agent 没有直接修改数据库的工具。

## QQ 和其他消息插件

本插件作用于同一个 DSH 宿主中的 Agent 会话。QQ 插件若把消息送入该会话、再将模型结果发回 QQ，记忆上下文就有机会影响 QQ 回复。

| 接入方式 | 当前边界 |
| --- | --- |
| 正常 DSH Agent，来源 `source.kind = user` | 可读取记忆，并按普通用户回合提炼新记忆；QQChat 文档描述的是这种形式 |
| 正常 Agent，来源为 `plugin` 或 `plugin:…` | 可获得该会话的稳定个人资料；当前不会把这些消息当作用户证据自动学习，也不会用它们更新主题检索词 |
| QQ 插件自行调用模型、不经过 DSH Agent | 不会经过本插件的上下文注入 |
| 未触发 Agent 的静默群消息 | 不会自动被本插件学习 |

**当前不支持 QQ 群成员身份隔离。** 默认同一伙伴跨会话共享个人记忆，内部用户为单一 owner；不能把它当作已经完成隔离的多人群聊记忆系统。不要把包含私人资料的伙伴直接开放到陌生人或群聊会话。可以在设置中关闭指定会话，但目前没有可靠的群成员识别和自动隔离策略。

本次验证覆盖 DSH 原生上下文装配和带 QQ 元数据的用户消息契约，未连接 QQ 账号，也未向任何联系人发送消息。对于具体 QQ 插件，应先在仅自己可访问的会话完成联调。

参考：[QQChat 架构](https://github.com/Coffeiz/dsh-qqchat/blob/main/docs/ARCHITECTURE.md)、[通到 QQ](https://github.com/Yuuyuko-uu/dsh-qq-bridge)、[DSH-IM](https://github.com/xmanrui/dsh-im)。这是接入机制判断，不是对上述插件所有版本的兼容承诺。

## 安装与开发

需要支持 `node:sqlite` 的 Node.js 22.21 或更新版本，以及 DSH 提供的 Agent、Session、模型、工具和系统提示服务。本地桌面运行时已经过集成检查；其他操作系统和远程 Web 部署尚未实测，当前管理接口按本机访问设计。

```sh
npm ci
npm test
npm pack
```

`npm pack` 会先构建并执行发布内容检查，生成 `dsh-feed-the-seek-0.2.15-beta.1.tgz`。初始测试版按本地包分发；尚未发布至 npm 或社区商城，清单保留 `private: true` 防止误发布。

普通 CLI profile 可安装本地包：

```sh
dsh plugin --profile tui add ./dsh-feed-the-seek-0.2.15-beta.1.tgz
```

桌面开发调试：

```sh
npm run dev:dsh
```

首次关联或修改依赖后重启 DSH，进入「设置 → 大肥鱼饲养手册」。开发命令在 Windows 默认安装目录寻找 DSH。退出开发链接并恢复安装版：`npm run dev:dsh:stop`。

安装脚本兼容旧包名，内部 `yuwen` 标识与数据路径保留，已有记忆不会因改名而丢失。

## 存储、密钥与费用

- 正式数据默认保存在 `$DSH_HOME/yuwen/memory.sqlite`；未设置 `DSH_HOME` 时为 `~/.dsh/yuwen/memory.sqlite`。项目内的演示与测试空间不用于正式记忆。
- 自动整理借用会话模型，**产生额外模型用量**。自动整理和语义增强是两种不同的调用。
- 默认本地检索不调用 Embedding 服务；启用语义增强后，待检索文本与需要建立索引的记忆会发送至所配置的接口。
- API Key 由 DSH credentials 服务保存，不写入普通设置或记忆数据库，前端只显示是否已配置；其落盘保护由宿主负责。
- 「测试连接」使用当前表单发送固定测试文字，不保存配置、向量、记忆或测试结果；连接成功后需按需保存配置和建立索引。
- 更换模型、协议或维度不会删除正文记忆；旧向量不能直接用于新模型的相似度比较，需要重新建立索引。服务失败时回退到本地检索。
- 记忆及原始来源可能含有个人信息。默认数据库不做额外的静态加密；分享导出文件前请检查内容。停用或卸载插件不会自动删除记忆。

## 本次发布检查

- 修复新消息文本与上轮相同时不刷新检索快照的问题。
- 修正旧集成测试的注入位置断言：个人资料属于稳定系统部分，不应在每轮相关记忆中重复。
- 自我整理遵守成长开关；融合不得跨项目、版本或条件，也不得提升证据强度。
- 人格改写与移除要求新观察证据，不能反复使用同一批证据制造变化。
- 升级 Zod 至修复版，保留嵌套默认值的行为。
- 发布采用文件白名单与自动检查；实测数据库、日志、宿主配置备份、生图脚本、个人路径与废弃素材不随包分发。

自动测试覆盖本地/向量检索、四元操作、来源校验、范围隔离、情绪衰减、自我融合、人格证据门槛、密钥与连接测试、原生设置和 DSH 宿主装配。成长时间门槛使用受控日期验证，不等于已经完成数周真实陪伴测试。
